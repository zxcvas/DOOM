# FOON marketing art

Original / transformative marketing graphics for the public landing page.
They are not ripped from an IWAD and are not a `PLAYPAL` dump.

| File | Role |
|------|------|
| `crt-screenshot-mock.png` | Authored 320×200 geometric framebuffer in a CRT bezel (hero / `#pixels`) |
| `palette-strip.png` | 32-color authored strip — FOON amber / phosphor / rust, **not** IWAD PLAYPAL |
| `architecture-diagram.png` | Diagram titled **FOON PIXEL PIPELINE** |

Regenerate with `python3 assets/_make_art.py` from this directory.

Do **not** add IWAD/PWAD files or commercial Doom data here.
